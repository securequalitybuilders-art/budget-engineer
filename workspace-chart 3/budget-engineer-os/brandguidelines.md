# brandguidelines.md — Dzenhare Budget Engineer OS

## Brand core
Dzenhare Budget Engineer OS should feel like a premium enterprise construction intelligence platform: calm, exact, trustworthy, and computationally powerful.

## Palette
- Deep Cobalt: `#1a365d` — primary structure, walls, authority
- Warm Sand: `#d4a574` — premium highlight, CTA, financial emphasis
- AI Cyan: `#06B6D4` — AI, live computation, openings/data highlights
- BIM Violet: `#8B5CF6` — BIM, model semantics, secondary highlights
- Dark Base: `#0b1220`
- Panel Surface: `#111c31`
- Border: `#24324b`
- Muted Text: `#94a3b8`
- Primary Text: `#e2e8f0`

## Typography
- Primary: Inter
- Display / technical headings: Space Grotesk when available
- Mono / data: JetBrains Mono when available

## UI principles
- Dark-first, enterprise-first.
- Surfaces should feel layered, not flat.
- Cards should be purposeful, not decorative.
- Use rounded corners with restraint.
- Charts, BIM elements, and CAD semantics should use consistent color meanings.

## BIM semantic colors
- Walls: Deep Cobalt
- Slabs / cost mass: Warm Sand
- Openings / dynamic data: AI Cyan
- Roof / BIM special layers: BIM Violet
- Selected / active object: Amber `#f59e0b`

## Layout
- Prefer Bento-style grids for dashboards.
- Left rail for controls/inspector, main panel for BIM/CAD workspace.
- Keep metadata dense but readable.
- Always prioritize decision-making over decoration.

## Motion
- Minimal, smooth, informative.
- Camera/orbit transitions should feel professional, not playful.
- Hover and selection states must improve comprehension.

## Voice
- Intelligent, practical, grounded.
- Avoid hype without proof.
- Construction affordability should feel credible and systems-driven.
